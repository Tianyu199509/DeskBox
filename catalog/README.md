# DeskBox Remote Catalog (`catalog/`)

本目录存放 DeskBox 自定义格子的官方远程数据源：

- `widgets.v1.json`：官方自定义格子远程目录镜像
- `prompts.v1.json`：官方自定义格子设计规范与提示词规则包镜像
