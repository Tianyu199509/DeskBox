# DeskBox 安装与首次配置指南

本指南帮助新用户从下载安装到创建第一个格子。完成后，你应该能够用 F7 显示或隐藏全部格子，并理解收纳目录、收纳格子和映射文件夹的区别。

> [图片占位：DeskBox 首次启动后的完整桌面，至少展示一个文件格子、一个待办和一个随记]

## 系统要求

推荐环境

- Windows 10 64 位（2004 / build 19041 或更高）或 Windows 11 22H2+
- x64 或 ARM64 处理器
- Windows App Runtime 2.5.1（Direct 安装包已内置，无需单独安装）
- 普通 Windows 用户权限

DeskBox 围绕 WinUI 3 的窗口、材质、圆角、拖放、通知与媒体会话能力设计。Windows 10 会将系统不支持的材质、圆角和部分动画降级为兼容表现；文件同步、拖放和核心格子操作仍按 build 19041+ 验证。

DeskBox 不需要以管理员身份运行。不要在快捷方式兼容性设置中勾选「以管理员身份运行此程序」。资源管理器通常以普通权限运行，DeskBox 如果被提升为管理员权限，Windows 可能阻止两者之间的文件拖放。

## 下载安装包

Direct 安装包可以从官网或 GitHub Release 获取。

- 官网：<https://deskbox.fun>
- GitHub Release：<https://github.com/Tianyu199509/DeskBox/releases/latest>
- 文件名：`DeskBox_Setup_<版本>_x64.exe`（Intel / AMD）或 `DeskBox_Setup_<版本>_arm64.exe`（骁龙、Surface Pro X 等 Windows on ARM 设备）

Microsoft Store 渠道由商店负责安装和更新。两个渠道的核心功能一致，但更新方式和部分渠道展示内容可能不同。

从 GitHub 下载时，发布页同时提供 `.sha256` 校验文件，可在安装前核对安装包完整性。

## 安装过程

Direct 安装包是 Full Native AOT 构建，内置匹配架构的私有 Windows App Runtime，不需要联网下载 .NET 10 或 Windows App Runtime。安装器仍会先检查目标电脑

- 依赖已经存在，直接跳过，避免重复安装。
- DeskBox 正在运行，先关闭进程，再替换文件。

这种方式可以控制安装包体积，也避免每次升级重复安装相同运行时。

> [图片占位：安装器依赖检查页面。分别标注「已安装，跳过」和「缺少，准备下载」两种状态]

## 首次启动引导

首次启动会打开一个五步引导。左侧是一块持续存在的演示舞台，每一步只讲一件事；右侧可以直接修改最常用的设置，舞台会立即按你的选择重新演示。

### 1. 认识两种文件格子

- **收纳格子**：接住桌面上的下载、截图和临时文件，拖进来的文件会移到它的收纳文件夹。
- **文件夹映射**：把已有的项目或资料文件夹直接摆上桌面，文件留在原处，路径不变。

### 2. 拖入收纳格子就是移动文件

这是引导中最重要的一步。默认拖入行为是移动：文件离开原位置，路径变为收纳文件夹。舞台会演示原位置留下空位、旧路径被划掉、新路径出现的全过程。

- 可以在这一步直接把拖入方式改为 **复制**（原文件留在原处，收纳文件夹多一份副本）。
- 软件安装目录、程序文件、代码仓库，或被其他软件按路径引用的工程素材，不要直接拖进收纳格子。已有文件夹请用托盘菜单的「新建文件夹映射」；程序请按住 Alt 拖入，只创建快捷方式。
- 收纳文件夹的位置显示在这一步，可以直接打开；更改位置请进入 `设置 > 文件格子`，DeskBox 会先复制并校验，再切换。

建议把收纳根目录固定到资源管理器的快速访问。收纳根目录不是数据库，里面仍然是普通文件夹和文件。

### 3. 随时唤起，随时收起

默认全局快捷键是 F7：按一次显示全部格子，再按一次隐藏。引导里可以点「试一下」，或直接按快捷键，舞台会跟随真实桌面状态。这一步也可以打开「双击桌面空白区域显示或隐藏全部格子」，或跳转修改快捷键。

### 4. 从托盘管理，常用设置一览

右键任务栏右下角的 DeskBox 图标，可以新建格子、新建文件夹映射或打开设置。这一步同时列出默认显示方式（胶囊）、窗口材质、开机自启和桌面整理的当前值，点击即可跳到对应设置页。

### 5. 启用功能格子

待办、随记、搜索、天气、音乐和时光都可以单独开启，开启后对应格子会立即出现在桌面上。新用户推荐先开启待办和随记。音乐依赖播放器是否支持 Windows 系统媒体会话，天气需要网络。

从第 3 步开始可以「跳过引导」；直接关闭窗口则会在下次启动时从当前步骤继续。
## 创建第一个格子

右键系统托盘中的 DeskBox 图标，选择创建格子。

建议第一个格子命名为「待处理」。它用于承接暂时不知道该归档到哪里，但不希望继续散落在桌面上的文件。

把一张不需要继续留在原位置的测试图片拖进去。默认拖入行为是移动，文件会从原位置进入格子对应的真实文件夹，不会额外保留一份副本。存放路径和拖入行为都可以在 `设置 > 文件格子 > 默认收纳路径` 中更改。

接着使用「映射文件夹」选择一个常用目录。映射不会复制目录，它直接展示真实位置中的内容。

## 新用户推荐初始配置

| 项目 | 推荐值 | 原因 |
| --- | --- | --- |
| 全局快捷键 | F7 | 单键显示或隐藏全部格子 |
| 收纳拖入 | 移动 | 拖入后直接清理来源位置，符合桌面收纳语义 |
| 附件保存 | 关联原路径 | 不重复占用磁盘空间 |
| 胶囊模式 | 先关闭 | 先熟悉完整格子的操作 |
| 待办预览 | 2 行 | 扫读与信息密度较平衡 |
| 随记预览 | 3 行 | 能看到足够上下文 |
| Enter 行为 | Enter 换行，Ctrl+Enter 保存 | 符合多行编辑习惯 |
| 自动叠放 | 先关闭 | 文件较多后再开启更容易理解效果 |

## 覆盖升级

从旧版本升级时，可以直接运行新安装包覆盖安装。正常情况下会保留

- 格子配置、位置和尺寸
- 收纳目录中的文件
- 待办、随记及其附件关系
- 外观、快捷键和其他设置
- 胶囊与展开状态的保存数据

重要版本升级前，建议进入 `设置 > 诊断与维护 > 设置与内容备份` 导出 ZIP 备份。覆盖安装不会替代数据备份。

## 卸载前检查

卸载前建议完成三件事

1. 在设置中确认当前收纳根目录。
2. 用资源管理器打开目录，确认重要文件可独立访问。
3. 导出一份 DeskBox 数据备份。

收纳格子中的普通文件不会因为应用消失就变成不可读格式，但卸载程序可能询问是否删除本地应用数据。操作前应看清选项。
