# DeskBox 随记格子：保存临时文字、链接、图片与 Markdown 笔记

正式笔记软件很完整，但打开它往往需要打断当前工作。随记格子处在桌面顺手处：先把临时想法、截图与链接接住，再决定固定复用、置顶常驻还是同步导出成标准 Markdown 文件。

> **1.6.0 功能边界提示：** 剪贴板自动采集历史、全局快捷粘贴弹窗（`Alt+V`）、离线图片 OCR 与敏感凭据 DPAPI 加密已由全新的独立 **剪贴板格子（Clipboard）** 专门承接；随记格子现专注于文字、链接、Markdown 笔记与多附件管理。

## 一句话理解随记

随记是一个本地优先的轻量桌面笔记与临时收件箱，通过 **“记录、固定”** 两个视图区分常规草稿与高频复用内容，支持独立置顶小窗与本地 Markdown 目录镜像。

> [图片占位：随记格子展示常规记录、固定模板与一条多图片附件记录]

## 两个核心视图

### 记录：已经决定要保存的内容

普通随记适合会议摘录、临时回复、链接、灵感、项目决策和需要稍后再用的资料。它支持响应式单/双栏布局、搜索、排序、Markdown 编辑与预览、多选复制和删除。

### 固定：反复使用的内容

地址、模板回复、常用链接、会议入口和项目规则，适合标记或拖入“固定”。固定内容会持续停留在醒目位置，也可一键拆出为**独立置顶小窗**方便对照参考。

## 创建、编辑与 Markdown 镜像

1. 进入 `设置 > 功能格子`，启用随记。
2. 从托盘创建或显示随记格子。
3. 点击新增入口，输入标题与正文（支持行内快速编辑：`Enter` 保存、`Ctrl+Enter` / `Shift+Enter` 换行，完整兼容中文输入法组词态）。
4. 点击记录进入详情页，可切换 Markdown 预览、添加图片或文件附件、调整纸张样式或置顶状态。
5. 需要与 Obsidian、Typora 等本地知识库联动时，可在随记设置中开启**本地 Markdown 目录镜像**，将随记同步映射为可读的 `.md` 文件。

## 图片、文件和多附件

一条随记可以包含多张图片和多个普通文件。列表中可以横向浏览图片，详情页可以逐张复制、查看文字或删除附件。

文件附件有两种保存方式：

- **关联原文件**：保存文件原路径，不制作副本；适合稳定的项目文件。
- **复制到 DeskBox**：保存托管副本；适合来自微信、浏览器下载目录或临时缓存的内容。

## 纸张样式不是分类系统

随记可以使用默认、纸张黄、薄荷绿、雾蓝、樱花粉等纸张样式。样式适合帮助视觉识别，例如：

- 黄色：临时内容。
- 蓝色：会议记录。
- 绿色：可复用模板。
- 粉色：灵感或参考。

不要为每条记录设计复杂颜色语义，最多保留三四种稳定含义，读起来会更快。

## 搜索与跨格子协作

随记格子内可以搜索记录，全局搜索弹窗也可以直接检索随记正文、链接和附件，并支持把搜索结果保存到随记。

随记适合保存上下文，待办适合推进下一步，文件格子适合放真实文件，剪贴板格子适合承接高频复制历史与 `Alt+V` 快捷回填——四者通过拖放与右键动作互相打通。

## 常见问题

### 随记和剪贴板格子有什么区别？

**剪贴板格子**负责在后台按规则自动记录系统复制内容，支持 `Alt+V` 快捷回填当前焦点窗口、离线图片 OCR 以及 DPAPI 加密脱敏；**随记格子**则是主动整理的轻量桌面笔记，支持置顶小窗、Markdown 镜像与多附件归纳。

### 随记和待办有什么区别？

随记优先保存上下文和材料；待办优先管理下一步、截止日期、提醒和完成状态。两者可以通过附件和复制动作配合使用。

### 原文件移动后，随记附件还能打开吗？

如果附件使用关联原路径，移动、改名、删除或断开外置磁盘后可能失效。需要稳定保存时，选择复制到 DeskBox。

### 随记可以代替正式笔记软件吗？

它更适合临时信息和高频复用内容；开启本地 Markdown 目录镜像后，也可以自然汇入你现有的本地 Markdown 知识库。
