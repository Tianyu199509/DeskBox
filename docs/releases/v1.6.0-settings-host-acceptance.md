## 已知边界（如实）
- 搜索内容开关（SearchIncludeDeskBoxContent）经应用器补齐，但主进程搜索引擎的值缓存语义可能有半秒级延迟（低影响）。
- 发布说明窗、引导窗、桌面整理窗仍在主进程（归属设计如此）。
- AOT 冒烟 harness 场景未新增宿主位（harness 单进程走 #if 老路径，零售零编译；1.7 随 harness 退役物理删除老路径）。
