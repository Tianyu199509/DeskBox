# DeskBox 1.6.2

A comprehensive experience, smoothness, and stability update consolidating all post-1.6.0 improvements. DeskBox 1.6.2 brings back a redesigned adaptive Desktop Search widget (`+` / `;` / `>` quick prefixes and pointer-exit privacy blur), enables standalone `Alt+V` Quick Paste without a desktop widget, isolates folder and file pickers out of process, makes `F7` quick-reveal icons appear instantaneously without wake flashes, and resolves capsule Z-order, Custom Widget `<input>` focus, Todo reordering, Clipboard image copy, non-ASCII Shell launch, and Windows 10 / Microsoft Store stability issues.

Release date: 2026-11-25.

## Highlights

- **Desktop Search widget returns & standalone Quick Paste (`Alt+V`).** Adaptive Micro, Compact Bar, Medium, and Large Search widget layouts with `+ ` quick todo, `; ` quick note, `> ` command execution, instant math evaluation, optional history, and auto-blur privacy mask; global clipboard capture and `Alt+V` Quick Paste now work standalone without a desktop widget, paired with theme-aware acrylic menus and crisp text shadows.
- **Instant `F7` icon reveal, zero-flash wake & smoother memory trimming.** Retains visible first-screen file icons and hot compressed icon bytes across hidden states so `F7` / double-click wake displays icons on frame 0 instead of hydrating row by row; relaxes working-set trim cadence to eliminate hover/reveal page-fault stalls, pre-applies wipe clips and extends DWM commit grace to prevent first-frame flashes, restores custom/panoramic backgrounds on wake, and stops Glance photo blink on desktop refresh.
- **Capsule Z-order, stack popovers & zero-ghost batch hide.** Keeps expanded capsules above lower-row collapsed capsules across desktop clicks and group restacks while blocking pointer-through hover steals; cancels deferred layer-restore timers on batch hide so hidden capsules never reappear on the desktop; fixes unactivated stack popover outside-click light-dismiss, context-menu rename grace, and close-button lease leaks.
- **Reliable rename, Custom Widget `<input>` focus & Todo `All`-view drag.** Fixes unresponsive Rename/Edit actions and IME composition interruptions across files, folders, stacks, stack popovers, widget titles, Todo items, and Quick Capture notes; adds host keyboard activation, smart-capsule collapse blocking, and live retained-patch updates while typing in Custom Widget `<input>` / `<textarea>` controls; fixes Todo drag-to-reorder in the `All` filter across active and completed partitions.
- **Clipboard image copy, non-ASCII / `.lnk` / Store launch, out-of-process pickers & Windows 10 stability.** Fixes NativeAOT WinRT marshaling for Clipboard History image copy, `System.Kind`, and traditional calendars; fixes "The directory name is invalid" errors in non-ASCII/CJK right-click menus, quoted-directory `.lnk` shortcuts, and Microsoft Store `LocalCache` launches; isolates folder/file pickers inside `DeskBox.ThumbnailProxy.exe`; and resolves Windows 10 `DesktopAcrylicController` cross-compositor crashes, Windows 10 solid-backdrop theme contrast, Quick Capture popout crashes, companion IPC shutdown hangs (`0x8001010E`), 5-second manual launch waits, 65-second AI keep-alive drops, and Smart App Control policy diagnostics.

See `CHANGELOG.md` for details.

## 中文说明

体验、流畅度与稳定性综合更新（合并 1.6.0 发布以来的全部体验升级与问题修复）。DeskBox 1.6.2 带来全新自适应「桌面搜索」组件（支持 `+` / `;` / `>` 快捷指令前缀与隐私遮罩），支持 `Alt+V` 快捷粘贴弹窗独立运行，将文件夹与文件选择器迁入独立进程消除选目录假死，实现 `F7` 唤起首屏图标秒显与零闪烁唤醒，并全面修复胶囊层级、自定义组件 `<input>` 焦点、待办「全部」拖拽、剪贴板图片复制、中文目录右键打开及 Windows 10 / 微软商店版稳定性问题。

发布日期：2026-11-25。

### 主要更新

- **桌面搜索组件回归与 `Alt+V` 独立快捷粘贴。** 搜索组件支持微尺寸图标、紧凑横条、中等卡片与大面板自适应切换（`+ ` 新建待办、`; ` 记录随记、`> ` 执行指令、即时算式求值、可选历史与离开自动模糊隐私遮罩）；无需在桌面放置剪贴板格子即可单独开启全局剪贴板采集与 `Alt+V` 快捷粘贴，右键菜单与浮层升级主题自适应亚克力与清晰文字阴影。
- **`F7` 唤起图标秒显、零闪烁唤醒与内存回收调优。** 隐藏期间保留展开态首屏可见图标与热区缓存，唤起第 0 帧即带齐图标不再逐排蹦出；放宽工作集静默裁剪阈值消除日常缺页卡顿，修复唤起首帧闪烁、自定义/全景背景丢失与桌面右键刷新时时光照片闪白。
- **胶囊展开层级、叠放弹窗外点收起与隐藏零残留。** 上排胶囊展开后稳定压住下方未展开胶囊且点击桌面不掉层，阻断被遮挡胶囊悬停穿透串点；批量隐藏时取消延迟层恢复定时器，根除隐藏后个别胶囊残留桌面；修复叠放弹窗点击外部自动收起、右键菜单重命名保护及关闭按钮交互锁泄漏。
- **重命名、自定义组件 `<input>` 焦点与待办「全部」拖拽全面修复。** 修复桌面钉住模式下文件、文件夹、叠放、盒子标题、待办及随记点击「重命名 / 编辑」无反应或输入法中断；补齐自定义组件输入框点击获焦、智能胶囊打字防收起与输入法组词期原地局部刷新；修复待办「全部」视图拖拽排序与已完成分区回弹。
- **剪贴板图片复制、中文路径右键打开、跨进程选择器与 Win10 / 商店版加固。** 修复 NativeAOT 下剪贴板历史图片复制失效、`System.Kind` 与系统传统历法空白；修复中文路径系统右键菜单、带引号起始目录 `.lnk` 及微软商店版 `LocalCache` 路径打开报「目录名称无效」；全部文件/目录选择器独立进程运行防卡死；根治 Win10 收起胶囊跨 `Compositor` 闪退、Win10 纯色回退深浅色错位、随记弹窗闪退、伴侣进程重启 `0x8001010E` 5 秒卡死与误报错、手动启动白等 5 秒、AI 二创 65 秒断流及安全策略拦截提示。
