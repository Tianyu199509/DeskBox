# DeskBox 1.5.0

DeskBox 1.5.0 is a feature and reliability update: automatic data snapshots, a redesigned Organize Desktop with Public Desktop support, in-widget folder-shortcut navigation, high-resolution Shell icons, per-widget text sizes and clock formats, an optional native Windows context menu, a fix for stale desktop icons after cross-volume drags, and further memory reductions in Settings and the file surface.

Released on September 7, 2026.

## Highlights

- **Automatic data snapshots.** Backups run on a configurable schedule — every 5 minutes to every 5 days, 3–30 retained snapshots — with an optional custom backup directory. Invalid hand-edited values are normalized to the nearest preset, and an unavailable custom directory falls back to the default recovery folder with a single notification per degradation cycle.
- **Redesigned Organize Desktop with Public Desktop support.** A desktop preview card expresses per-file selection through clear tile opacity; re-scans keep previous selections, newly appearing files start unchecked, and the entry action is now "Preview organize". The source picker can optionally include the shared Public Desktop — moving its files may request administrator approval, canceled approvals keep completed personal-desktop work, and interrupted operations can be resumed or recovered at startup.
- **Folder shortcuts navigate in place.** A `.lnk` pointing inside the widget's own managed tree opens inside the file widget instead of File Explorer; external, broken, or unverifiable shortcuts keep the default system behavior.
- **High-resolution, correct icons.** Files, folders, and `desktop.ini` custom icons use 256-px Shell icons with shortcut overlays preserved; `.url` icons resolve through the Shell (with a bounded text-parse fallback), so Steam covers and per-user associations display correctly. Icon requests are throttled through a bounded queue.
- **More control over text, clock, and menus.** Quick Capture and Todo gain independent list and content text-size sliders; the Glance clock gains follow-system / 24-hour / 12-hour formats; a new optional setting shows the native Windows context menu for single file tiles (off by default).
- **Reliable rename and drag completion.** Inline rename fields receive keyboard focus reliably in every entry point (group title, file item, stack popover, Quick Capture), with a 300 ms focus-reclaim window. Internal drag completion waits for the Shell drop and revokes provisional Move acceptance, so reorders cannot trigger shortcut cleanup.
- **Stale desktop icons after cross-volume drags are fixed.** Dragging files into a grid across volumes now posts Shell change notifications (per-item rename plus a forced directory refresh), so Explorer views — including OneDrive-backed desktops — no longer keep stale icons of moved files until a manual refresh.
- **Lower memory, faster Settings.** Settings sections are created on demand and closed sections release their bindings; the settings search index is generated from localization keys and finds not-yet-created sections. Thumbnail proxy payloads read zero-copy, file items instantiate only the active layout, and widget title icons load lazily.
- **Safer file operations.** Same-directory drops (including junction/symlink-resolved) are rejected with feedback; recursive copies detect link cycles; folders cannot be moved into themselves; network-rooted or environment-variable shortcut targets are no longer marked broken; Steam shortcuts survive unavailable libraries; JSON stores use a verified in-place fallback and backup recovery.
- **More compact interface.** Widget title bars use a 40-px minimum row with tightened padding; group tabs use a native TabView appearance with a translucent selected background; Quick Capture and Todo capsules show a static preview instead of a scrolling marquee; the Settings update section is a clearer detail flow.

## 中文说明

DeskBox 1.5.0 是一次功能与可靠性更新：数据自动快照、整理桌面重设计并支持公共桌面、文件夹快捷方式就地导航、高分辨率 Shell 图标、小组件独立字号与时钟格式、文件格子原生右键菜单开关、跨盘拖入后桌面图标残留的修复，以及设置与文件界面的进一步内存优化。

2026 年 9 月 7 日发布。

### 主要更新

- **数据自动快照。** 备份可按 5 分钟到 5 天的计划运行、保留 3~30 份快照，支持自定义备份目录；手工编辑写出的非法值会归一化到最接近的预设，目录不可用时自动降级到默认恢复目录并每轮只提醒一次。
- **整理桌面重设计并支持公共桌面。** 桌面预览卡用明确的透明度表达逐文件勾选；重新扫描保留之前的选择，新出现的文件默认不勾选，入口动作改为「预览整理」。来源可选择纳入公共桌面——移动其文件可能弹出管理员授权，取消授权时个人桌面已完成的部分保留，被中断的操作可继续恢复，下次启动也会提示处理挂起的恢复。
- **文件夹快捷方式就地导航。** 指向格子自身收纳目录内的 `.lnk` 直接在格子内展开；外部、损坏或无法验证的快捷方式仍按系统默认方式打开。
- **高分辨率、正确的图标。** 文件、文件夹和 `desktop.ini` 自定义图标使用 256px Shell 图标并保留叠加层；`.url` 图标由 Shell 解析（保留带超时的文本解析兜底），Steam 封面和按用户关联的图标可正确显示；图标请求经有界队列限流。
- **文字、时钟与菜单更可控。** 快捷捕捉/待办独立的列表与正文字号滑杆；时光时钟跟随系统/24 小时/12 小时格式；新增文件格子原生右键菜单开关（默认关闭）。
- **重命名与拖拽收尾更可靠。** 内联重命名框在所有入口都能可靠获得键盘焦点，300 毫秒内被抢走的焦点自动夺回；内部拖拽等待 Shell 放置完成并撤销临时接受，排序不会再触发快捷方式清理。
- **修复跨盘拖入后桌面图标残留。** 把文件拖进另一个磁盘的格子后，资源管理器视图（包括 OneDrive 同步的桌面）不再残留已移走文件的图标：托管移动现在补发 Shell 变更通知（逐项改名加强制目录刷新），无需手动刷新。
- **内存更低，设置更快。** 设置分区按需创建、关闭时回收绑定；搜索索引由本地化键生成，未创建的分区也能被搜到。缩略图载荷零拷贝读取、文件项只实例化当前布局、标题图标按需加载。
- **文件操作更安全。** 同目录放置（含 junction/符号链接解析）提前拒绝并反馈；递归复制检测链接循环；文件夹不能移进自身；网络根目录和环境变量快捷方式目标不再被误标损坏；Steam 快捷方式在库不可用时保留；JSON 存储使用验证式就地回退与备份恢复。
- **界面更紧凑。** 标题栏最小行高 40 并收紧内边距；小组标签改用原生 TabView 外观；快捷捕捉与待办胶囊改为静态预览、不再滚动长文本；设置的更新分区重构为更清晰的详情流。
