# DeskBox 1.4.7

DeskBox 1.4.7 focuses on stability for Windows Shell integration, high-DPI stack popovers, desktop-layer transitions, and Native AOT bindings.

Released on August 29, 2026.

## Highlights

- **Isolated More system operations.** Extended Windows Shell context menus run in `DeskBox.ThumbnailProxy.exe`, so a faulty third-party Shell extension cannot terminate the DeskBox process. If the helper fails, DeskBox reports the operation as failed without falling back to in-process Shell code.
- **High-DPI stack layout.** A 3×3 popover containing five files now keeps the expected 3+2 arrangement at fractional DPI scales. The requested cell geometry is explicit and the viewport reserves a physical-pixel-safe guard.
- **Desktop-layer stability.** Hidden desktop-layer widgets remain hidden during Explorer drag and activation transitions, while expanded capsules preserve their peer ordering.
- **Native AOT calendar bindings.** Glance calendar day decorations retain the generated binding metadata in Direct Native AOT builds.
- **Existing 1.4.6 fixes retained.** This build includes the shortcut-transfer safety, multi-display layout memory, performance modes, Everything integration, and other 1.4.6 improvements.

## 中文说明

DeskBox 1.4.7 重点修复 Windows Shell 集成、高 DPI 叠放弹窗、桌面层级切换和 Native AOT 绑定问题。

发布日期：2026 年 8 月 29 日。

### 主要更新

- **隔离“更多系统操作”。** 扩展 Windows Shell 菜单改由 `DeskBox.ThumbnailProxy.exe` 独立进程承载，第三方 Shell 扩展异常不会结束 DeskBox 主进程；代理失败时只报告操作失败，不回退到进程内 Shell 实现。
- **修复高 DPI 叠放布局。** 3×3 弹窗放入五个文件时，即使使用分数 DPI 缩放，也保持第一行 3 个、第二行 2 个，不再错误排成 2+2+1。
- **稳定桌面层级。** Explorer 拖拽和激活状态切换期间，隐藏的桌面层格子不会偶发重新显示；展开胶囊保持正确的同层级顺序。
- **修复时光日历 AOT 绑定。** Direct Native AOT 构建保留日历日期装饰数据的绑定元数据。
- **包含 1.4.6 的既有修复。** 包含快捷方式传输安全、多显示器布局记忆、性能模式、Everything 集成等 1.4.6 改进。
