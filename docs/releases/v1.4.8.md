# DeskBox 1.4.8

DeskBox 1.4.8 is a reliability and compatibility release focused on safer managed-storage handoff, Windows 10 rendering behavior, search interaction, and the Full Native AOT distribution path.

Released on August 29, 2026.

## Highlights

- **Safer managed-storage handoff.** DeskBox maintains an independent `DeskBox Files.lnk` shortcut to the managed storage folder. Existing users keep the default-on behavior, the path follows a storage migration, and the uninstaller offers to create a collision-safe shortcut when managed files remain.
- **Windows 10 corner compatibility.** Windows 10 uses square outer and capsule-media corners at render time while preserving the saved preference for a later Windows 11 upgrade. Windows 11 continues to follow the selected corner mode.
- **Simpler weather default.** New installations and restored defaults use the Standard weather skin; the richer skin remains available as an explicit choice.
- **More reliable search keyboard navigation.** Arrow keys keep the selected result and its highlight synchronized. Ctrl+Tab changes tabs without leaving arrow keys controlling only the scroll view.
- **Cleaner search tabs.** Search tabs are text-only, content-sized, and use a taller, better-spaced selection indicator.
- **Safer Windows integration.** Mapped junctions and symbolic links resolve to physical traversal paths, Shell confirmations follow Explorer settings, persistent watcher failures back off, and virtual-display layouts recover when a usable display appears.
- **High-DPI stack layout.** Stack popovers preserve their requested column count at fractional DPI scales instead of wrapping a 3-column grid unexpectedly.
- **Offline Full Native AOT installers.** Standard x64 and ARM64 installers bundle the matching Windows App Runtime and carry the generated install manifest used for safe in-place upgrades.

## 中文说明

DeskBox 1.4.8 是一次以可靠性和兼容性为重点的版本更新，主要改进收纳文件交接、Windows 10 显示行为、搜索交互和 Full Native AOT 安装包。

发布日期：2026 年 8 月 29 日。

### 主要更新

- **更安全的收纳文件交接。** DeskBox 会维护独立的 `DeskBox Files.lnk` 快捷方式，指向当前收纳目录；老用户默认启用，收纳路径迁移后会跟随更新，卸载时发现仍有收纳文件则询问是否创建不会覆盖其他文件的快捷方式。
- **Windows 10 圆角兼容。** Windows 10 在实际渲染时使用直角外框和胶囊媒体内图，同时保留用户保存的圆角偏好，之后升级到 Windows 11 可继续使用；Windows 11 会按所选圆角设置应用。
- **天气默认样式更简洁。** 新安装和恢复默认设置时，天气默认使用简洁的标准样式，丰富样式仍可手动选择。
- **搜索键盘操作更可靠。** 上下键会同步选中结果和高亮；按 Ctrl+Tab 切换 Tab 后，方向键仍用于选择文件，不会只滚动列表。
- **搜索 Tab 更干净。** Tab 只保留文字，宽度按内容适配，文字两侧留出更舒适的间距，并使用更高的指示条。
- **Windows 集成更稳定。** 映射目录的联接和符号链接会解析到物理访问路径，Shell 确认框跟随资源管理器设置，持久性监视失败会退避，虚拟显示器恢复后会重新放置格子。
- **高 DPI 叠放布局修复。** 分数缩放下叠放弹窗保持请求的列数，不再意外换行。
- **离线 Full Native AOT 安装包。** x64 和 ARM64 标准安装包内置匹配架构的 Windows App Runtime，并包含用于安全覆盖升级的安装清单。
