# DeskBox 1.6.1

A focused experience, smoothness, and stability update. DeskBox 1.6.1 brings back a redesigned adaptive Desktop Search widget with quick `+` / `;` / `>` prefixes and an optional privacy mask, allows `Alt+V` Quick Paste to run standalone without a desktop widget, moves all folder and file pickers out of process so Shell extensions can never freeze the UI, and resolves rename/focus and Z-order responsiveness issues reported since 1.6.0.

Release date: 2026-11-25.

## Highlights

- **Desktop Search widget returns.** Adaptive Micro, Compact Bar, Medium, and Large layouts with `+ ` quick todo, `; ` quick note, `> ` command execution, instant math evaluation, optional search history / recently opened items, and pointer-exit privacy blur.
- **Standalone Quick Paste (`Alt+V`) & menu polish.** Use global clipboard capture and `Alt+V` Quick Paste without placing a Clipboard widget on the desktop, paired with theme-aware acrylic context menus and crisp text shadows.
- **Reliable rename & keyboard focus.** Fixes unresponsive Rename/Edit actions and IME interruptions across files, folders, stacks, stack popovers, widget titles, Todo items, and Quick Capture notes in desktop-pinned mode, and eliminates focus/retry loops on widget title rename.
- **Freeze-free pickers & smoother desktop performance.** Isolates all folder and file pickers inside `DeskBox.ThumbnailProxy.exe` (with dark-mode sync and automatic parent-exit cleanup), stops desktop-floor Z-order restacking storms above wallpaper helpers, and moves Recycle Bin state probes and Settings path checks off the UI thread.
- **Steadier capsules, custom widgets & resilient diagnostics.** Fixes a composition race crash when placing a newly created Custom Widget from Workshop onto the desktop, capsule drag/cancel-merge placement jumps, Todo custom due-date overlay focus, post-update layout recovery, update progress ordering, and adds a 15-second standalone fallback for diagnostics export.

See `CHANGELOG.md` for details.

## 中文说明

体验、流畅度与稳定性更新。DeskBox 1.6.1 带来全新自适应「桌面搜索」组件（支持 `+` / `;` / `>` 快捷指令前缀与隐私遮罩），支持 `Alt+V` 快捷粘贴弹窗独立运行，将全部文件夹与文件选择器迁入独立进程彻底消除选目录假死，并集中修复了 1.6.0 发布后反馈的重命名无响应与界面卡顿问题。

发布日期：2026-11-25。

### 主要更新

- **桌面搜索组件回归。** 支持微尺寸图标、紧凑横条、中等卡片与大尺寸面板自适应切换；输入 `+ ` 新建待办、`; ` 记录随记、`> ` 执行指令或直接计算算式，可选展示搜索历史与最近打开项目，并支持指针移出自动模糊隐私遮罩。
- **快捷粘贴弹窗（`Alt+V`）独立运行与菜单打磨。** 无需在桌面放置剪贴板格子即可单独启用全局剪贴板采集与 `Alt+V` 快捷粘贴；右键菜单与浮层升级主题自适应亚克力与文字阴影。
- **重命名与输入焦点全面修复。** 修复桌面钉住模式下文件、文件夹、叠放标题、叠放弹窗项目、盒子标题、待办事项及随记点击「重命名 / 编辑」无反应或输入法选词中断的问题，消除盒子重命名失焦引发的重试与焦点循环。
- **选目录不再假死，日常交互更跟手。** 全部文件夹与文件选择器均在独立原生代理进程中运行（同步深色主题、宿主退出自动清理），消除第三方外壳扩展或网络盘引发的主界面卡死；修复壁纸辅助窗口导致的底层反复重排、回收站状态探测卡顿及设置页磁盘检测阻塞。
- **组件创建、胶囊拖拽与诊断导出加固。** 修复工坊新建自定义组件放置桌面时的动画竞态闪退、智能胶囊标题栏拖拽或取消分组合并后的位置跳变、待办自定义到期日浮层焦点竞态、升级后布局恢复与更新进度顺序，并为导出诊断包提供 15 秒独立应急兜底。

完整变更列表请见 `CHANGELOG.md`。
