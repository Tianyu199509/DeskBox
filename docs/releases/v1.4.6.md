# DeskBox 1.4.6

紧急修复了部分系统下，格子间拖动 `.lnk` 快捷方式会被误删除并进入回收站的严重问题。

DeskBox 1.4.6 is the largest feature and runtime update since 1.4.3. It adds configurable performance policies, monitor-topology-aware layouts, new activation shortcuts, a redesigned file-stacking workflow, Everything-powered file search, deeper Windows Shell integration, and a Native AOT Direct package.

Released on August 28, 2026.

## Important before updating

- DeskBox now uses Windows App SDK and Windows App Runtime 2.4 instead of 2.2. If the PC only has the runtime used by 1.4.3, the Direct installer will download and install Windows App Runtime 2.4 once during this update.
- The runtime download happens only when 2.4 is missing. Windows may request a restart after installing it. For a fully offline update, install the matching x64 or ARM64 Windows App Runtime 2.4 before running DeskBox setup.
- GitHub Direct packages now use Native AOT, so a separate .NET 10 runtime is no longer downloaded or required.
- A normal in-place update keeps the existing settings, layouts, Todo, Quick Capture, and managed files. The minimum supported system remains Windows 10 21H2 (build 19044).

## Highlights

- **Performance modes and resource controls.** Balanced, Resource saver, and Custom modes control cache retention, transient-window release, and continuous decorative animations. Hidden and inactive surfaces now release recreatable UI and image resources more deliberately.
- **Multi-display layout memory.** DeskBox keeps separate layouts for known monitor topologies and restores positions, sizes, groups, and capsule placement after display, work-area, or DPI changes. New monitors receive an in-bounds proportional layout.
- **Move a whole display together.** Hold Ctrl while dragging a widget title to move all eligible widgets on the current display. Moving and resizing also share configurable snapping and spacing.
- **More ways to summon DeskBox.** Choose F7, double Ctrl, Alt+Space, Win+Space, a Win-key tap, or a custom shortcut. An optional double-click on a blank desktop area can show or hide every widget, and Quick Reveal can temporarily surface widgets above other windows.
- **File stacking 2.0.** Manual stacking and automatic grouping now have separate switches. Stacks can open inline or in a dedicated Adaptive, 3×3, or 5×5 popover with material choices, screen-edge placement, scrolling, and the same icon/density controls as a file widget.
- **Smoother stack interaction.** Popovers keep hover-expand capsules and groups open while they are in use, support Ctrl+mouse-wheel sizing, and no longer flash the previous stack's content when switching.
- **Closer to Windows file interaction.** Selection geometry now follows the desktop style. File names can be hidden, icon size can be overridden per widget, drag/drop can follow the Windows default, and Shell transfers show per-item progress.
- **Expanded file operations.** Added shortcut creation, confirmed permanent deletion, selected-target elevation, pointer-positioned More menus, and Windows 10-compatible More system operations. Folder rename, shortcut icons, and path tooltips also received fixes.
- **Everything-powered search.** DeskBox queries Everything's existing local index over IPC and merges those results with DeskBox content. Connection setup, advanced syntax, and system-noise filtering are available in Settings. Everything itself is not bundled and must be installed separately.
- **Appearance and media controls.** Widget text and monochrome controls can follow the theme or use light, dark, custom, and per-widget values. Glance adds image transparency, and Music can switch sources or follow the system session.
- **Safer startup and storage.** Startup waits for Explorer's desktop icon host before attaching desktop-layer widgets, reducing the risk of disturbing icon restoration. External managed-storage loss no longer discards widgets, and desktop organization reports retained-item reasons in detail.
- **Native AOT and reliability work.** Settings dropdowns, stacks, Glance, Music, Todo, Quick Capture, attachments, support QR images, persistence, weather caching, and repeated window interaction were hardened for the new Direct build.

## 中文说明

DeskBox 1.4.6 是自 1.4.3 以来规模最大的一次功能与运行环境更新，新增可配置的性能策略、多显示器布局记忆、更多唤起方式、重新设计的文件叠放、Everything 文件搜索、更完整的 Windows Shell 操作，以及 Native AOT 直发安装包。

发布日期为 2026 年 8 月 28 日。

## 更新前必读

- DeskBox 使用的 Windows App SDK 与 Windows App Runtime 已从 2.2 升级到 2.4。如果电脑只有 1.4.3 使用的旧运行时，本次通过官网下载的直发安装包更新时，会额外下载并安装一次 Windows App Runtime 2.4。
- 只有缺少 2.4 时才会下载。运行时安装完成后，Windows 可能要求重启。完全离线更新时，请先手动安装与电脑架构一致的 x64 或 ARM64 Windows App Runtime 2.4。
- GitHub 直发包改为 Native AOT，不再需要也不再下载单独的 .NET 10 运行时。
- 正常覆盖更新会保留现有设置、格子布局、待办、随记和收纳文件。最低支持系统仍为 Windows 10 21H2（build 19044）。

## 主要更新

- **性能模式与资源控制。** 新增“均衡”“节省资源”“自定义”三种模式，可控制缓存保留、临时窗口释放和持续装饰动画。隐藏与非活动界面会更有计划地释放可重建的界面和图片资源。
- **多显示器布局记忆。** DeskBox 会为不同屏幕组合分别保存布局，在显示器、工作区或 DPI 变化后恢复格子位置、尺寸、分组表面和胶囊位置；新显示器会获得限制在屏幕内的比例布局。
- **整屏格子一起移动。** 按住 Ctrl 拖动格子标题，可整体移动当前显示器上的可移动格子。移动和调整尺寸共用可配置的吸附与间距。
- **更多唤起方式。** 可选 F7、双击 Ctrl、Alt+Space、Win+Space、单独按 Win 或自定义快捷键；也可以双击桌面空白区域显示或隐藏全部格子，“快捷唤起层”则可临时把格子显示到其他窗口上方。
- **文件叠放 2.0。** 手动叠放与自动归组拆分为独立开关。叠放可在当前布局内展开，也可使用自适应、3×3、5×5 独立弹窗，并支持材质选择、屏幕边缘适配、滚动和文件格子同款图标/密度控制。
- **更顺畅的叠放交互。** 操作弹窗时，悬停展开的胶囊和格子组会保持展开；支持 Ctrl+鼠标滚轮调整图标，并修复切换叠放时首帧闪现旧内容的问题。
- **更接近 Windows 的文件交互。** 选中区域改为接近桌面图标的形状；文件名可隐藏；每个格子可单独设置图标大小；拖放可跟随 Windows 默认行为；Shell 文件传输会显示逐项进度。
- **更多文件操作。** 新增创建快捷方式、带确认的永久删除、仅提升所选目标的管理员启动、靠近鼠标位置的“更多”菜单，以及兼容 Windows 10 的“更多系统操作”。文件夹重命名、快捷方式图标和路径提示也完成修复。
- **Everything 文件搜索。** DeskBox 通过本机 IPC 查询 Everything 已有索引，并与 DeskBox 内容合并显示。设置中提供连接引导、高级语法和系统噪声过滤。Everything 应用本身不会随 DeskBox 捆绑，需要单独安装。
- **外观与媒体控制。** 格子文字和单色控件可跟随主题，也可使用浅色、深色、自定义和单格子覆盖；时光支持图片透明度；音乐支持切换播放源或跟随系统会话。
- **更安全的启动与存储。** 开机时会等待 Explorer 桌面图标宿主稳定后再挂接桌面层格子，降低干扰图标布局恢复的风险。收纳磁盘临时断开不会丢失格子，桌面整理也会详细列出项目保留原因。
- **Native AOT 与可靠性修复。** 针对新直发版加固设置下拉框、文件叠放、时光、音乐、待办、随记、附件、支持二维码、数据保存、天气缓存和反复窗口交互。
