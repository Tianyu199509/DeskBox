Its WinUI 3 widgets are backed by ordinary local files and folders, so users keep familiar Windows behavior without a proprietary file database. DeskBox requires no account, supports x64 and ARM64 Windows PCs, and is released under GPL-3.0-only.

## Full product description

DeskBox is a free, open-source desktop organizer for Windows. It adds native-feeling WinUI 3 file and folder widgets without replacing Explorer, so files remain ordinary local files and folders. Users can collect desktop clutter, map existing folders without moving them, search the PC, and keep lightweight todo, note, weather, and media controls nearby. DeskBox requires no account, stores its working data locally, and supports Windows PCs with x64 or ARM64 processors. The project is maintained by solo maker Tianyu Zhu and released under GPL-3.0-only. Direct installers and source code are published through GitHub, with an optional paid Microsoft Store edition supporting continued maintenance.

## Maker bio

Tianyu Zhu is a product designer and solo maker building native-feeling Windows tools. He created DeskBox through AI-assisted development and remains responsible for its product direction, interaction design, testing, release engineering, and technical tradeoffs. DeskBox is a public, inspectable record of that work: a WinUI 3 application with automated tests, x64 and ARM64 releases, and twelve selectable interface languages.
