# 多屏功能 v2 — 真机验证清单（2026-10-08）

> 按依赖顺序排列：A 单机可做 → B 双屏核心 → C 特殊硬件 → D 拍板项。逐条验证，**失败时记录：条目编号 + 截图 + 大致时间点**（我去查 DeskBox.log 对应行）。构建：`src\DeskBox\bin\Debug\net10.0-windows10.0.22621.0\DeskBox.exe`（当前已运行此版本）。

---

## A. 单机即可验证（约 10 分钟）

**A1｜设置页基础视觉**
设置 → 常规 → 显示器与格子。
✅ 预期：预览画布显示一块屏（紧凑 200px 高）；卡内大号居中编号；底部徽标行——主显示器=主题色实底胶囊、若"新格子出现在"=指定此屏则多一枚描边"新格子"徽标；**任何位置不得出现 `\\?\DISPLAY#...` 这样的机器码**。

**A2｜识别按钮**
点「识别」。
✅ 预期：屏幕上闪一个大号数字（跟随系统主题色），约 3 秒后渐隐消失；数字大小约为屏高的三分之一（不是缩成小角标）。

**A3｜右键菜单结构**
右键任意格子 → 「移到显示器」。
✅ 预期：单屏时**整个子菜单不出现**。

**A4｜新格子默认落点**
托盘/菜单新建一个文件格子，鼠标放在屏幕右侧。
✅ 预期：新格子出现在**鼠标所在的屏**、**右上角对齐**（右缘 24px、顶部 72px 附近）；再建一个应向下错开（级联）。注意：这改变了旧行为（旧=主屏左上 100,100），确认你能接受。

**A5｜"新格子出现在"设置**
设置页该下拉三个选项（鼠标所在的显示器/主显示器/每块在线显示器）。
✅ 预期：切换后新建的格子按所选落位；选择"主显示器"后新建落在主屏右上。

## B. 双屏核心（接上第二块屏，30-40 分钟）

> 建议外接屏记为 E，内屏记为 L。以下"归属"= 格子属于哪块屏（菜单打勾/设置页行下拉显示的值）。

**B1｜拖动跨屏 = 归属更新（核心心智，S6）**
把一个格子从 L 拖到 E 松手。
✅ 预期：格子留在 E；右键菜单打勾在 E；设置页该行显示 E。之后 F7 隐藏再唤起、重启 DeskBox，格子仍在 E。

**B2｜右键菜单移动（S19）**
右键格子 → 移到显示器 → 选另一块。
✅ 预期：格子立即移过去（位置按比例映射），归属更新。再点当前已打勾的那项 → **什么都不应发生**（无闪动、位置不变）。

**B3｜菜单离线归属显示（H1 修复）**
先把某格子归属 E，然后拔掉 E。
✅ 预期：右键菜单出现一条**禁用**行，显示"原显示器 ××××（未连接），重新连接后自动回到那里"——×××× 应是 E 的友好名（如 DELL U2720Q）或"原显示器（未连接）"，**绝不是机器码**。设置页"各格子所在显示器"该行下拉同样验证。

**B4｜主显示器切换 → 格子不动（S1，行为变更）**
两屏都有格子，Windows 设置里把主显示器从 L 改为 E。
✅ 预期：所有格子**原地不动**（不再跟随主屏搬家）；只有"始终在主显示器"的格子移到新主屏。

**B5｜"始终在主显示器"开关（S7）**
给某格子开"始终在主显示器"，拖它到副屏松手。
✅ 预期：松手后归属自动变为副屏（不再跟随主屏）；菜单里 radio 与 toggle **不会同时打勾**（M1 修复）。关掉开关 → 格子留在当前屏不动。

**B6｜拔屏 → 4 秒宽限后迁移（S3）**
格子在 E，拔掉 E。
✅ 预期：**前 ~4 秒格子不动**（宽限），随后出现在 L 上（尺寸按两屏比例缩放）；归属仍记住 E。

**B7｜回插 → 原位恢复（S4）**
接回 E。
✅ 预期：格子回到拔前在 E 的位置与尺寸，与拔前一致。

**B8｜回退态调整不丢原布局（S5）**
重复 B6 后，趁格子临时在 L 时拖到 L 的另一个位置，然后接回 E。
✅ 预期：回 E 的原位（不是 L 上拖到的位置）；再拔一次 E → 格子出现在 L 上你拖到的位置。

**B9｜分辨率/缩放往返（S2，v4 核心）**
改 E 的分辨率（如 2560×1440→1920×1080）→ 挪一下格子位置 → 改回原分辨率。
✅ 预期：改回后格子位置与改前**完全一致**；期间挪动过的位置不复活旧布局（改动保留在 DIP 意图里）。缩放比例（125%↔150%）同理验一遍。

**B10｜显示器排列拖动**
Windows 显示设置里拖动 E 从 L 右边换到左边。
✅ 预期：格子跟随各自屏移动，不产生新布局档案、不跳屏。

**B11｜断开收起为胶囊（S23，H4 修复——重点验）**
设置页 → 多显示器 → 显示器断开时 → 选"把它的格子收起为胶囊"。拔掉 E。
✅ 预期：E 上的格子**真的在 L 上收起成胶囊**（窗口实际收起，不是只在重启后生效——这条之前是坏的）。接回 E → 自动展开回原位。断开期间手动展开过某格子 → 回插后**不**自动展开它。

**B12｜把所有格子移到这里 + 撤销（S20）**
选中 E 的屏卡 → 点"全部移到此显示器"。
✅ 预期：先弹确认框（数量+他屏计数；全部已在此屏时文案省略"其中 0 个"）；确认后全部移到 E，InfoBar 带"撤销"；点撤销 → 所有格子逐字段恢复原样（归属/位置/尺寸）。

**B13｜撤销过期保护（H3 修复）**
执行 B12 后，**手动拖动其中任一格子**，再点 InfoBar 里的"撤销"。
✅ 预期：提示"布局已变化，无法撤销"——**不**把你的手动调整回滚掉。

**B14｜设置页热插屏自刷新（H5/S27 修复）**
设置页开着不动，拔掉再插回 E。
✅ 预期：预览画布、屏信息卡、各行下拉**立即自动刷新**（不需要切走再切回来）。

**B15｜胶囊跨屏**
把一个收起的胶囊从 L 拖到 E 松手。
✅ 预期：胶囊留在 E，归属更新为 E（再唤起/重启仍在 E）。若有胶囊条（多胶囊排列），整条拖跨屏 → 条上**每个**胶囊归属都更新。

**B16｜组与拖出**
两个格子合并成组，整组拖到 E；再从组里拖出一个成员丢到 L。
✅ 预期：组整体归属 E；拖出的成员立即归属 L（下次唤起不弹回 E）。设置页列表里组显示"格子组（N 个格子）· 成员：…"。

**B17｜新建落点（S21/S22）**
"新格子出现在"分别设为：鼠标所在屏（鼠标放 E 上新建→落在 E 右上）；主显示器；指定 E。然后把指定 E 改回鼠标屏。
✅ 预期：三者落位正确；指定的屏拔掉后下拉显示禁用项"××（未连接，暂用鼠标指针所在的显示器）"，新建实际落鼠标屏。

**B18｜锁屏/睡眠（S12）**
锁屏 1-2 分钟再解锁；或睡眠唤醒。
✅ 预期：解锁后格子全部原位，无中间跳动；日志无异常（我来查）。

**B19｜Win+P（S15/S10）**
切"复制"→ 格子按单逻辑屏排布；切回"扩展" → 全部归位。"仅第二屏幕"（合盖场景）→ L 的格子去 E、开盖回来归位。

## C. 特殊硬件场景（有条件再验）

**C1｜DP 显示器自动休眠 / KVM 切换（S11）**：显示器电源键关再开，或 KVM 切走再切回（几秒内）。✅ 预期：**格子完全不动**（宽限内恢复=什么都不做）。这是 Rapid HPD 场景。

**C2｜扩展坞/DisplayLink 冷启动（S14）**：关机→接坞→开机（显示器晚几秒到）。✅ 预期：**不出现**"先全部挤到内屏、再搬回外接屏"的过程（启动等待最多 5 秒）。

**C3｜远程桌面（S16）**：RDP 登录后在远程会话里拖动格子。✅ 预期：远程会话里布局正常；断开回到本机物理屏 → 全部归位，归属不变。

**C4｜全屏游戏改分辨率（S13）**：独占全屏游戏把分辨率临时改掉再退出。✅ 预期：游戏期间格子不重排、退出后原位。

**C5｜虚拟屏/远控软件（H1 兜底）**：如你常用 GameViewer/Parsec 类，断开后看离线归属文案。✅ 预期：显示"原显示器（未连接）"固定文案，无机器码、无 `{0}` 字面量。
